# The Layers header on one line

With the Mask button there, the panel's header ran 7 px over and the three action buttons dropped onto a second
line. The row now asks its own width, and the words **New layer** give way before the buttons do.

- **before-dark / before-light**: Vector and Pixel on one line, duplicate, mask and delete on the next.
- **after-dark / after-light**: all five on one line. Each button still says or shows what it does, and the group is
  still called New layer for a screen reader.
