# Pixel sheet mode: how the sprite sheet export shows which way you are in

Real Export dialog (Sprite sheet, three-board "Blob sprites" demo) with injected mock markup, dark and light.
Today the dialog has two stacked rows for this ("Which artboards" and "What's on it"); both are hidden in the mock.

- **A**: one row, "Where the sprites come from", four cards with diagrams (One picture, An animation, Frames on boards, Sprites on a sheet). The one that matches the file is lit; you can change it here. A live "Your sheet" preview sits under the format cards and the footer tells the truth ("12 frames on 3 sprites, one sheet of 128 x 96 px").
- **B**: Quill says it in a sentence ("This sheet has 3 sprites ... one per board") with a single "Change how it is built..." link. Quieter, fewer controls.
