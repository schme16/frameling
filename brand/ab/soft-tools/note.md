# Soft paint as tools: the build

The chosen layout (A, with Illustrator's pull-outs). Each picture exists dark and light.

- `before-*`: development as it was. `after-*`: this branch.
- `compare-dark.png` and `compare-light.png`: the whole look on one sheet.
- `*-rail-pixel` and `*-rail-vector`: the rail on a pixel layer and a vector layer.
- `after-pullout-pixel`, `after-pullout-vector`, `after-retouch-vector`: the pull-out open from the Brush and Retouch buttons.
- `after-pullout-narrow`: the one-per-group rail, a narrow window, the Draw button held.
- `before-menu` and `after-menu`: the Soft paint menu on the bar, and Tools > Soft paint.
- `pullouts-dark.mp4` and `pullouts-light.mp4`: click, press and hold, pick from the pull-out, then Shift+F changes the button (H.264).
