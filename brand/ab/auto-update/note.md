# Update offer

Board task `auto-update`. Each picture exists dark and light, cropped to the card and captioned.

- **offer-appimage-*.png** is what you see on a Linux AppImage (and, in the same shape, a Windows installer copy): what is new in the release's own words, then **Skip this one**, **Not right now** and **Update now**. Nothing is downloaded until **Update now**.
- **offer-page-*.png** is a copy that can't swap itself (a Mac, the Windows portable build, the beta copy): it says why in one line, and the main button opens the release page instead.

The card sits in the corner rather than stopping the window, and only turns up when nobody is drawing.
