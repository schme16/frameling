# Pixel chooser: nothing picked first, or An animation pre-picked?

Quill's real "Pixel time! What are we making?" dialog (the state after the click in B is the real dialog too).

- **A (built, recommended)**: nothing is picked and Start waits; Quill says "Not sure? Pick An animation. You can switch any time and nothing is lost." Each card gets its own line when picked.
- **B**: An animation is pre-picked and Start is ready, so a hurried person gets there in one click. Fewer clicks, but it decides for people who have not read the four answers.
