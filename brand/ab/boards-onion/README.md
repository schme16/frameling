# Onion skin: the boards either side

The Ball film demo (three shots as artboards), open on shot 2, "Close-up: the face", frame 1. Onion skin on, one
board each way.

- **a-off:** onion skin on, **Show the boards either side too** off. Only this board's own frames are ghosted, and
  on frame 1 there's nothing before it, so the stage is plain.
- **b-on:** the same with boards on. The wide shot's last frame comes in behind (the hill and the ball arriving at the
  right) and the landing shot's first frame on top of it (the ball up high), so the cut lines up.

Dark and light, cosy look, 900 x 700 crop of the 1400 x 900 window.
