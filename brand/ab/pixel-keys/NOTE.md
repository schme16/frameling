# Aseprite keys: how someone coming from Aseprite finds them

- **A**: the first time a pixel file opens, Quill asks once ("Coming from Aseprite?") in the same ask-the-first-time dialog as "Opening pixel art" (a registered choice: remembered, changeable in Preferences). Options: Use Aseprite keys, Use Frameling keys.
- **B**: no question. Preferences > Keyboard shows the shortcut sets as cards, with an Aseprite card that lists its main keys. (The real page also keeps its key list below; the mock hides it.)
