# Interface size

The same window at **100%** and at **150%** (Preferences, General, Interface size). On the desktop this is Chromium's
own page zoom, so every part stays sharp rather than being blown up; in a browser tab it is the same thing in CSS.

The canvas area is smaller in layout terms once everything else is bigger, which is why the fitted page shows smaller
here. On a 2k or 4k screen, where the window holds far more, that is the point: readable panels with plenty of room
left for the drawing.
