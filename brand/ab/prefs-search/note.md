# Searching Preferences

Board task `prefs-search`. Each picture exists dark and light. The box at the top of Preferences takes the focus when it opens; everything below is the real app, typed into.

- **1 smoothing** (`prefs-search-1-smoothing-*`): "smoothing" is what Photoshop and Procreate call the stabilizer, so it finds the stabilizer on Pen and tablet. The first row is lit (the one Enter would go to); the commands that mention it come last, under their own heading.
- **2 hotkeys** (`prefs-search-2-hotkeys-*`): "hotkeys" (also "shortcuts", "keymap", "key bindings") lands on the Keyboard page first.
- **3 dark mode** (`prefs-search-3-dark-mode-*`): finds Mode on General and the Themes page, both under their page names.
- **4 typo** (`prefs-search-4-typo-*`): "stablizer" still finds the stabilizer. "stabiliser" (British) and "colour" for "color" work the same way.
- **5 canvas size** (`prefs-search-5-canvas-size-*`): the picture size choice in Behaviour, found by what other apps call it.
- **6 nothing** (`prefs-search-6-nothing-*`): says so plainly and offers the help search for the same words. Enter does the same.
- **7 landed** (`prefs-search-7-landed-*`): "palm rejection", then Enter: the Pen and tablet page opens scrolled to the row, lit for about two seconds so you learn where it lives.

Up and down move through the results, Enter goes there, Esc clears the box (a second Esc closes Preferences).
