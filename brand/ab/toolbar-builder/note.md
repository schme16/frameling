# Change the tools: the Builder, working

The Builder shape (C) from `brand/ab/toolbar-custom/`, built for real. Both clips are the real app (Draw workspace,
Bouncing ball), shot in xvfb, H.264, 720x640, about 19 seconds each. Dark and light are the same run.

- `tool-builder-dark.mp4`, `tool-builder-light.mp4` (with `-poster.png` stills)

## What the clip shows, in order

1. **Change the tools** opens from the command search (it is also in View > Change the tools and the rail's right-click
   menu). The rail gets a gold edge, a gold **+** on every divider, and a name and a fold arrow over every group. The
   panel beside it holds Put away, Button size, Group names, what to do with tools that do not work on this layer, Rail
   style and **Put the tools back**.
2. **Rename a group.** Click **Shapes**, type **Blocking**, Save.
3. **Make a group.** Click the Star, choose **Start a new group here**. The new group has no name, so it shows as
   **Name it** here and as a plain divider once you press Done. That is all a divider is.
4. **Move a tool.** Drag Text up into the drawing group.
5. **Put one away.** Drag the Eraser onto **Put away**. It leaves the rail but keeps its place, and is still on its key and in
   the command search.
6. **Fold a group.** The arrow beside **Select** turns the group into one button with a corner mark (press and hold for the rest).
7. **Put the tools back.** One press: groups, names, the hidden Eraser, the fold, size, names and style all go back.
   A message with **Undo** follows (it is off screen in this crop).

## Rules it keeps

- A tool is in exactly one place. Put away is a flag inside its group, not a second list, so it comes back where it was.
- Twins (the Lasso and the Pixel lasso) move, hide and come back as one.
- Everything is optional fields on the arrangement that was already saved (`hidden`, `fold`), and the workspace file stays at version 1.
