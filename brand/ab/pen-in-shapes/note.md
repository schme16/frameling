# Pen and point editing in the Shapes group

Board task `pen-points-in-shapes-group`. Each picture exists dark and light. Left to right: before, A, B.

- **Before.** Pen and edit was a group of its own: Transform, Edit points, Pen.
- **A (built).** Shapes holds line, rectangle, ellipse, polygon, star, shape builder, text, then Pen, then Edit points. Nothing that was there moves; the group's button still shows Line first.
- **B.** Pen and Edit points sit straight after Star, so the outline tools are next to the shapes and the shape builder and text come after them.

Transform had no home once the group went, so it joins Select (after the ways of picking).

Files: `rail-before-A-B-{dark,light}.png` (the open rail), `flyout-before-A-B-{dark,light}.png` (the rail on One per group, the Shapes group's menu open).
