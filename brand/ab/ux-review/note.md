# UX review pictures

Taken in the built app under xvfb (scripts/shoot.cjs, 1400 x 900 unless said), first run, then a doodle, a pixel sprite,
an opened example and the menus. Each picture backs one `ux-` task.

- 01-hello-small-window-bubbles-clip.png: first page of Quill's hello at 1280 x 720. Six bubbles are stacked in the left column and the first one is cut off at the top. The five cards on the right look like the pickable cards on the next page but are not clickable.
- 02-four-questions-in-one-minute.png: four question sheets from about six ordinary clicks (N, then + and - on the timeline). Top right and bottom left are the same sheet; Escape closes it without remembering, so it comes back. Every one of these was asked with a single layer and nothing after the drawing.
- 03-draw-menu-same-names.png: the Draw menu. Select, Lasso and Polygon select each appear twice (one pair greyed), all with the same keys (V, B, G, E), and the list runs off the bottom of the window.
- 04-workspaces-only-in-view-menu.png: the only visible place to switch between the Draw, Animate and Pixel workspaces. The menu bar also has menus called Draw, Pixel and Animate, which are not the same thing.
- 05-timeline-icon-row.png: the timeline toolbar and the layers header. About fifteen controls with no words; "Hold -" shows a dash; Vector and Pixel read like a mode switch but add layers.
- 06-layer-add-buttons-and-tool-rail-reshuffle.png: left, a vector layer; middle, after pressing Pixel; right, after pressing Vector again. The tool rail rearranges itself each time. The status bar in the middle one shows the new pixel layer is 160 x 90 on a 1280 x 720 page, with no word about it.
- 07-right-rail-quests-quill-things-help.png: Quests, Quill, His things and Help. The tab says "His things", the panel says "Quill's things", and Quill's pencils live in a third place.
- 08-pixel-start-nothing-picked.png: New pixel art after pressing Start with nothing picked. Quill's own line says "Pick An animation", but nothing is picked and Start does nothing.
- 09-palette-first-open.png: the command palette on first open, before anything has been used. It is an alphabetical list that starts at "Add a camera".
- 10-onboarding-settings-step.png: step four of the hello. Units (px, mm, cm, in, pt), Mouse wheel, Look, Reduce motion and more, before a single mark has been made.
- 11-webm-defaults-to-av1.png: Preferences > Behaviour. WebM video codec is AV1 by default. The Export dialog never says so.
- 12-questions-at-the-moment-of-starting.png: left, "Workspace follows the drawing" asked straight after Start on a new pixel sprite; right, a stray click beside it asks "Pressing beside a dialog" as another question.
- 13-layers-panel-and-timeline-same-list.png: the Bouncing ball example in the Animate workspace. The Layers panel and the timeline's layer column are the same list with the same add buttons.
- 14-small-laptop-draw-workspace.png: Draw at 1280 x 720. The tool rail scrolls, the Panels button is cut off at the bottom of the right rail, and the page is at 33%.
- 15-onboarding-what-would-you-make.png: step two of the hello. The interest cards pick a starting workspace and example only.
- 16-blank-doodle-quiet-and-properties-wall.png: what Skip for now gives you. A white page with no hint to draw, Quill gone, and a right panel opening on a long run of brush sliders.
- 17-rig-effects-help-menus.png: Rig, Effects, Plugins and Help menus. Rig, Bone, Pose, Slim bones; three Shortcut set entries inside Help.

## Already lovely, so it does not get sanded off

- The New pixel art sheet: four little pictures that show each way to build a sprite, with a size row and Quill's one-line advice.
- The Export dialog: plain names first (Animated GIF, MP4 video, PNG sequence, Sprite sheet), the file type second, one line on what each is for, and a frame count and size at the bottom.
- Skip for now: the toast says "No problem! Say hi to Quill again any time from Help > Meet Quill again."
- A new drawing holds until the next one, and the timeline tooltip says what you can drag.
- The choice sheets themselves: every option says what it does, with "Remember my choice" and where to change it.
- The status bar tips ("Made a mistake? Ctrl+Z takes it back, as many times as you like.").
- The empty marker and clip lanes saying what they are for.
- The command palette's plain descriptions ("Each piece fades in (or out).") and the examples on the welcome sheet.
- Workspaces described by job in Preferences, and Features letting a person switch whole areas off.
- The quest list showing locked lessons with "Try it anyway".
