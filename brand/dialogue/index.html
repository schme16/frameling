Reading the live lines

Write over any line and it's kept as you go. When you're happy, Put these in the app raises a task on the board and Claude merges your words into lines.json. Words in {curly} brackets are filled in by the app (a name, a theme), so keep them exactly. Where a line is a list, put one item per row. Click a picture to see it full size.

What happens to the words I write
  • One box, one line. A single line stays a single line, and a line break you type inside it is kept as a break. Nothing else is touched.
  • A list is one row per item. Each row is a bubble shown in turn, or one of a set the app picks from (the note under the name says which). Blank rows and spaces at the ends are dropped. Adding a row adds a bubble; a single line can't become a list, since that needs a code change.
  • {Curly} words must match. The app swaps them for a name or a theme. If one is lost, added or misspelled, the line turns red and isn't sent, so the app never says "{name}" out loud. In a list, each word only has to turn up once across the rows.
  • Only the words change. Where it shows and which {curly} words it takes stay as the app has them. A brand new line needs a code change and a picture, so ask for it as a task instead.
  • Open a changed line and What this becomes in lines.json shows the exact row that gets written.
  • Safe if anything goes wrong. Edits are kept in this browser and on the board. If the board can't be reached they stay in the browser, and Download my changes gives the file that npm run dialogue:apply takes.
